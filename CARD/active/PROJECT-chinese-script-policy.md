# 專案：chinese-script-policy

## 這個專案要的是什麼

1. **一棵字表、多個露出面**：轉換與偵測共用同一份資料，不各寫一份。
2. **完全離線**：沒有網路呼叫，沒有遠端字典。
3. **要出貨，而且出貨的那一份也要過**：`npm pack` 之後解開來跑同一套測試（`test:tarball`），
   交付清單漏檔在 checkout 裡是**看不見**的。
4. **術語要一次改完所有露出面**：CLI 的 `--help`、網頁標籤、函式庫參數、示範 app 的 API 欄位、
   以及 `package.json` 的 `description`——它們不會自己同步（`npm run test:api` 的術語守門釘住這一條）。

## 界線

- **發版的那一步必須由使用者在自己終端機跑**：非 TTY 環境 `npm publish` 會立刻 `EOTP` 失敗，
  而且印出來的網址會被遮蔽成 `***`。agent 只能把前置備好。
- 這一張的 `goal` 由 **AIPMSkills 工作區的 agent 代擬**（2026-09-20，採用三步的第 2 步）。
  使用者當天看過，回覆是「**我明白了**」——那是**理解，不是核准**，所以 `goal` **仍然是草稿**。
  要改就直接改這一行。
- 卡片**不出貨**；索引在 `PUBLISHING.md` 第 5 節（`README.md` 是 npm 的對外門面）。
